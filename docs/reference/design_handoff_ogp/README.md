# Handoff: まる見え政治資金 — OGP 画像（確定版 R6）

webapp の各ページを X などでシェアしたときに出る OGP 画像（1200×630）の最終デザイン。
デザイナーが Claude で作った検討ページ（claude.ai の artifact「まる見え政治資金 OGP 確定版」）から、確定した **R6** だけを書き出したもの。

|---|---|

| `images/00_top@2x.png` | 同じ画像の 2 倍解像度版（2400×1260）。静的な既定画像としてそのまま使える |

`design/` の HTML は検討過程の関数（A / C / P1〜P3 / F / R〜R5 など）も残っているが、起動時に `DIRS` を R6 だけに絞っており、**正は R6**（`ogR2(w, i, {r6:true})` と、そこから呼ばれる `r6Bg` / `r2Frame` / `r2Mark` / `cvSkC` / `ogRTop`）。
画像は base64 で HTML に埋め込まれている（`window.IMG`）。

## About the Design Files

`images/` の PNG が見た目の正。`design/` の HTML はモックであり本番コードではない。
inline style をそのまま移植せず、webapp の既存の色・書体・サンキー図の描き方に合わせて再現すること。
金額は作成時点のサイトの 2026 年の数字で、議員の調研費の一部は UI 確認用のダミー。**本番では各ページのデータから描く。**

## 共通の枠（トップ以外）

- 画像全体 1200×630。外周はミント〜グリーンのメッシュ状のグラデーション（地色 `#9CE2D3`）。
  淡いミント `#F0FCF8` の楕円 2 つと、濃いグリーン `#2AA693` / `#3DBBA8` の楕円 2 つを外周に置いた配色を全員でそろえ、
  **楕円を置く位置だけを 1 枚ずつ変える**（同じ見た目が続かないように）。位置はページごとに決まった値になればよい（毎回変わらない）
- 外周の内側に、左上 (26, 26)・1148×578・角丸 26px の白い紙。紙の外側に細い白線と、ごく薄い影
- 右下にチームみらいのロゴ（約 172×147、紙の角からはみ出す）と、その左に「まる見え政治資金」（40px・極太・字間 .14em）
- 文字色は緑みのある黒 `#0A0F0D`、補助のグレー `#48564F`、区切り線 `#D3E0DB`。和文は Noto Sans JP（字詰め palt）、金額の数字は Poppins

## 見出し（上段）

左右 64px の余白、上から約 54px（政党は 44px）に、高さ 122px の横並び。

- **顔**：議員・政治団体は丸い顔写真（直径 122px、白い 4px のふち＋薄い影）。政党は顔の代わりにチームみらいのロゴ（約 86×74）
- **タイトル**：「{名前}{の調研費 / の政治団体 / の収支}」。名前を大きく、「の〜」は名前の 56〜78% に小さくする。1 行に収まるよう、名前の長さで文字の大きさを決める
- **右端に総額**：左に区切り線を引いた 2 つの数字
  - 議員：「支給」（緑 `#2AA693` の四角）と「支出」（赤 `#DC2626` の四角）
  - 政党・政治団体：「収入」「支出」
  - 数字は「1,537万」「7億2,656万」のように万単位（「億」「万」は和文で小さく）。政党は桁が多いので数字を小さめ（約 39px、ほかは約 60px）

## サンキー図（下段）

- **サイトのそのページに載っているサンキー図と同じ区分・同じ形**（政党・政治団体は「詳細の区分」の図、議員は調研費の図）
- 画像では金額・割合・「合計」のラベルを出さず、区分名だけを出す
- 図の上端は見出しの下に薄くフェードして重なる
- 真ん中の濃いグレーの棒（合計）が画像の左右中央（x=600）に来るように帯の長さを決める
- 右端の棒はロゴより左に置き、区分名は細い線で引き出して並べる。ロゴに帯や棒が欠けて隠れないようにする
- 区分名が重なるときは上下にずらし、細い線で棒とつなぐ

## トップ（`00_top.png`）

ほかとは別の構成。左に「まる見え／政治資金」（大きな 2 行）と「政党と議員のお金をまるごと公開」、左下にロゴ、右にサイトの画面を写したノート PC と電話。
**データに依存しない静的な画像**なので、`00_top@2x.png` をそのままサイトの既定の OGP 画像にしてよい。

## 公開準備中（`15_member_prep.png`）

調研費がまだ無い議員向けに作られた案（顔は人型、総額なし、図の代わりに「公開準備中」の帯）。
導入するかは別途決める（現時点の方針は、描けるデータが無いページはトップの画像にフォールバックする）。
