調査研究費とは
正式名称は「調査研究広報滞在費」、2022年までは「文書通信交通滞在費」と呼ばれていました。国会議員1人あたり毎月100万円、年1200万円が支給される公費です。
・全額が税金です。歳費（議員の給与）とは別に支給されます
・使えるのは議員活動のみ。選挙運動には使えません
・2025年8月の法改正で、使途の報告と残額の国庫返還が義務になりました
・チームみらいでは、法令に加えて党の自主基準（公務・議員活動に限定／第三者による承認）を設けています

実データで分かった負荷 1万円以下が296件中277件（94%）、金額では36%。全件表示すると月40件前後の行が並びます。4月は99件。月切り替えは必須です。
同一注文の分割行が多数あります。4/23のトナー代¥7,722が10行、4/1のクリアファイル¥850が7行、8/16のグラス代¥683が5行。Amazonの明細を1品目ずつ起こしているためで、市民には「同じものを何度も買っている」と読まれます。注文単位でまとめるか、まとめ買いと明記するかの判断が要ります。
タクシー代は86件・¥301,780。行き先を伏せる運用にすると、この件数がすべて非公開になります。
B-5 データについて
調研費とは／使える範囲と使えない範囲／チームみらいの自主基準／集計方法と更新頻度／免責
すべての支出を1件ずつ、領収書つきで公開しています。領収書を徴し難かったものが1件あります（5/12 電気代 ¥8,300：電力会社より請求書のみ発行）。
余った分：221万円を使い、479万円は使っていません（7ヶ月分・年末時点で確定します）
実データ「領収書等を徴し難かった事情」欄に記載があるのは全296件中1件のみ。この欄をどう表示するかは未設計でしたが、実データでは例外的に少ないため、B-5に文章で書く形で足りそうです。
