## 1. このデザインが果たす役割

制度が変わるのを待たずに、変わったあとの姿を先に実演する。批判されている「領収書が見られない」「1万円以下が分からない」「公開が年1回」を、法改正を待たずに自分たちで解消して見せる。

**判断に迷ったときの原則**

| | 目指す | 目指さない |
|---|---|---|
| 1 | 預金通帳のように1件ずつ追える | 集計とグラフだけ見せる |
| 2 | 調研費を知らない人が一覧して分かる | 制度用語をそのまま並べる／数字を丸める |
| 3 | 何になったかまで分かる | 全支出に成果を求める／広報の場にする |
| 4 | 未使用分は内訳のひとつとして静かに置く | 返還額を成績にする／議員を金額で比べさせる |
| 5 | 議員室が続けられる公開ラインにする | 理想の線を決めて事務所に頑張ってもらう |

## 3. セクション定義

### A-6 調査研究費（政党ページ・新規）

| 要素 | 内容 |
|---|---|
| 見出し | 議員12人の調査研究費サマリー |
| リード | 国会議員に毎月支給される公費を、何に使ったか |
| 日付 | **2026年2月〜8月分を公開中（峰島事務所のみ）　2026.8.20時点** |
| コラプス | 「調査研究費とは」1つのみ。閉じた状態が初期値 |
| 区分トグル | 詳細の区分／法律上の区分（既存A-1と同じ見た目） |
| KPI | 2枚のみ。支給された ¥7,000,000／議員活動に使った ¥2,212,581 |
| グラフ | 横棒（円は不採用）。未使用分は含めない |
| 議員リスト | 行が「一覧」と「グラフの絞り込み」を兼ねる。選択行は反転＋左ドット黒 |

議員リストの列：`ドット / 議員名 / 支出 / 公開状況 / 詳細ボタン`。返還額の列は作らない。並び順は当選期順で固定、ソート機能なし。準備中の議員もグレーで表示する。

### B-1 使いみちの流れ

KPI 2枚 → 区分トグル → サンキー。サンキーは左端が支給700万円、右端に費目が並び、**最後に「未使用」を固定**。未使用は淡色（#EFEEE7相当）＋細い輪郭線で、他の帯より明らかに後退させる。「国庫へ返還」とは呼ばない。

### B-2 1年間の推移

上下対向の棒グラフ。中央のゼロ線から上が支給（毎月100万円で一定）、下が支出。9〜12月は点線の空枠。

### B-3 主要な支出の成果（新規）

```
① 活用方針      グレー帯・左に太い罫。議員本人が書く1〜2行
② 主要な支出     カード3枚。金額・日付・費目・件数・目的・成果物チップ
```

成果物チップは動画・レポート・議事録など。第三者の記録（議事録）を混ぜる。人件費・事務所費のような運営費は対象外。

### B-4 すべての支出

| 要素 | 内容 |
|---|---|
| リード | 金額にかかわらず、すべての支出を1件ずつ、領収書つきで公開しています |
| 区分トグル | 詳細／法律上 |
| **月切り替え** | 2〜8月のセグメント。**必須**（4月は99件） |
| テーブル列 | 日付 / カテゴリー / 項目 ＋ⓘ ＋領収書チップ / 金額 |
| ⓘ | 特記事項。クリックで直下に注記行が開く |

### B-5 データについて

既存の「データについて」と同構成。末尾に「余った分：221万円を使い、479万円は使っていません（7ヶ月分・年末時点で確定します）」。

## 5. やらないこと

- 返還額をKPIカードにしない。サマリーの横棒に含めない。数字を出すのはサンキーの最終帯とB-5本文の2箇所のみ
- 議員リストに返還額の列を作らない。ソート機能を付けない
- 円グラフを使わない（15分類だと扇が細かくなりすぎ、返還が面積で目立つ）
- 準備中の議員を隠さない
- 成果セクションを金額上位で機械的に埋めない
- 調研費だけ特別な配色やレイアウトにしない

## 7. デザインで解きたい課題

**1. 同一注文の分割行。** 4/23にトナー代¥7,722が10行、4/1にクリアファイル¥850が7行、8/16にグラス代¥683が5行並びます。Amazonの明細を1品目ずつ起こしているためで、そのまま出すと「同じものを何度も買っている」と読まれます。注文番号でグルーピングして折りたためるか、まとめ買いを1行に集約するか。

**2. 1万円以下が94%・277件。** 全件公開の方針は決まっていますが、金額の大きい支出が小額の行に埋もれます。並び順、視覚的な強弱、月内でのまとまりをどう作るか。

**3. タクシー代86件・¥301,780。** 交通費91件のうち86件がタクシーです。同じ項目名が延々と並ぶ画面をどう見せるか。

**4. 議員リストの行が2機能を持つ。** 行クリックでグラフ切り替え、行内ボタンで遷移。触って迷わないかの検証が要ります。
