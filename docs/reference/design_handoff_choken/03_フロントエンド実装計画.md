# 03 フロントエンド実装計画

hifi プロトタイプ `design/調研費 管理画面.dc.html`（admin）と `design/調研費まる見え.dc.html`（webapp）が見た目・挙動の正。**スタイルは既存コンポーネント（`admin/src/client/components/ui/*`・`docs/admin-ui-guidelines.md`・globals.css のトークン）で再現**し、プロトタイプの inline style は移植しない。

## A. admin — シェルの変更（既存画面に影響あり）

### A-1. グローバルセレクタ（サイドバー上部）

- サイドバーのブランド直下に「現在の対象」カード。teal 枠（`--color-ring`）・accent 背景。上段に種別ラベル（「政治資金・政治団体」/「調査研究費・議員室」）、下段に対象名＋年度＋caret
- クリックでオーバーレイ（Dialog）。**2グループ**：「政治資金（政治団体）」= チームみらい／デジタル民主主義を考える会 × 2025・2026 の4件、「調査研究費（議員室）」= 議員×年度。現在の対象に check アイコン＋accent 背景
- **明示的に選ぶまで対象は変わらない**。全画面の loader / action はこのコンテキスト（URLパス or cookie。既存が orgId をどう持つかに合わせる）にスコープされる
- 補足文言：「切り替えるまで、すべての画面はこの対象に対して操作されます。メニューも対象に合わせて変わります。」

### A-2. モード切替サイドバー（`sidebar-nav.ts` の再構成）

- **政治団体モード**：`政治団体`（政治団体マスタ）／`データ取り込み`（取引一覧・取引一括削除・CSVアップロード・残高登録）／`報告書`（取引先マスタ・取引先紐付け・寄付者マスタ・寄付者紐付け・報告書エクスポート）— 既存画面は変更なし、配置換えのみ
- **議員室モード**：`議員室`（議員・年度帳簿）／`調査研究費`（書類スキャン・仕訳の確認・編集〔下書き件数の赤バッジ〕・支給の登録・公開・支出群と成果・読み取りプロンプト）
- **「ユーザー情報」ページは削除**。ユーザー管理（admin only）は据え置き
- 既存画面の各ページ内 PoliticalOrganizationSelect は撤去し、グローバルコンテキストから取得

## B. admin — 調研費の各画面

ルーティング案は `/(auth)/research-fund/...`。各画面 PageHeader（英字ラベル + teal-soft 下線 h1）を使用。

| 画面 | 要点（プロトタイプ進拠） |
|---|---|
| **議員**（一覧） | カードグリッド。氏名＋/slug、政党バッジ（membershipあり=accent、なし=グレー「無所属（政党なし）」）、当選年月。操作：年度帳簿／編集／削除（右端・destructive）。ヘッダー右に「議員を追加」primary |
| **議員 新規/編集**（別ページ・同一フォーム） | 氏名*・スラッグ*・当選日*（支給の起点）・所属（select、任意。**既存 political_organizations から選択**。新規は既存の政治団体作成画面へ誘導し、政党テーブルは作らない）。編集はプリフィル。削除は確認ダイアログ：「年度帳簿・仕訳・領収書・公開ページもすべて削除されます。…公開済みのデータがある場合は、削除ではなく非公開化を検討してください。」 |
| **年度帳簿** | 「◯◯の帳簿一覧」＋切り替えリンク。年度カード：公開中バッジ・公開範囲・支給累計・支出累計・確認待ちn件（赤）・「スキャンする」「仕訳を確認」。＋破線の新規作成カード |
| **書類スキャン** | ドロップゾーン（破線 teal・「{議員}／{年度} の帳簿に追加されます」バッジ・JPG/PNG/PDF・最大30枚）。バッチカード：進捗バー＋「12件中8件完了・1件失敗」＋「完了分を確認へ」。ジョブ表：ファイル（アイコン＋名前）／状態ピル（完了=teal塗り・失敗=赤塗り・処理中=teal枠・待機中=グレー枠）／抽出結果の要約／失敗行に「再実行」。処理中はポーリング |
| **仕訳の確認・編集** | ステータスタブ（すべて/下書き/確認済/公開中・件数つき）＋月セレクト。左：テーブル（日付/カテゴリーピル/項目〔分割n/m・領収書なしバッジ〕/金額/状態ピル）。行クリック＋**↑↓キー**で選択（input内では無効）。右：sticky パネル＝領収書プレビュー（原寸で開く）or「領収書なし（手動作成）」破線枠／日付・金額・項目名・科目 select（21分類マスタから。「複式の仕訳（借方◯◯／貸方 普通預金）は自動で作られます」注記）・特記事項（公開される）・**備考（公開されない・グレー背景＋バッジ）**／「確認済にする」primary＋破棄 destructive＋前へ次へ。フッターに source・モデル・プロンプト版。ヘッダー右「手動で仕訳を作成」 |
| **支給の登録** | テンプレートカード（毎月1日・¥1,000,000・借方普通預金/貸方調査研究費収入・編集）。月次リスト：登録済み（check）／当月「この月を登録」primary／未到来グレー。注記「下書きを経ずに確認済で作成」 |
| **公開** | 左：確認済・未公開のチェックリスト（日付・項目・金額）＋「n件（¥合計）を公開する」（未選択時 disabled）。右：**サンキー before/after**（BEFORE=グレータグ・AFTER=tealタグ。左ノード=支給¥7,000,000、右=費目ノード＋末尾に未使用〔#EFEEE7・細枠〕）。チェックで after と差分文（「公開すると：◯◯ +¥n・未使用 −¥n」）が即時更新。サンキー実装は webapp の SankeyChart 流用 |
| **支出群と成果**（一覧） | 帳簿全体の「活用方針」textarea＋保存。グループカード：タイトル・**金額（自動集計）・件数・期間**・説明（teal 左罫）・成果物チップ（URLあり=accent／なし=グレー「報告は準備中」）・編集 |
| **支出群 新規/編集**（別ページ・同一フォーム） | 左：タイトル*・説明*・成果物リスト（ラベル＋URL、追加/削除、「URL空なら『報告は準備中』と表示」）。右：**仕訳の紐づけ**＝チェックリスト＋上部に金額・件数・期間のライブ自動集計。「人件費・事務所費のような運営費は成果カードの対象外」注記 |
| **読み取りプロンプト** | 本文エディタ（monospace）＋「v3 有効」バッジ＋「保存して v4 にする」。テスト実行カード：書類 select＋実行→抽出JSON表示（仕訳は作らない）。右：版履歴（版番号・変更要旨・日付・使用ジョブ数・有効バッジ・「巻き戻し」） |

### 状態・ピル定義

- 仕訳ステータス：下書き=グレー枠 #666／確認済=teal枠 #089781／公開中=teal塗り #30BCA7 白字
- カテゴリーピルは既存 `category-pill.ts` の支出形式（白背景・カテゴリ色の枠と文字）に調研費カテゴリ21分類の色を追加登録（プロトタイプ内の科目リストは旧15分類の一部を使ったサンプル。実装はマスタが正）
- 空状態・ローディング・エラーは既存 TransactionsClient のパターン（中央寄せ text-muted-foreground / destructive）

## C. webapp — 公開ページ

正は `design/調研費まる見え.dc.html`（hifi）＋ `design/wireframe/choken-marumie-design-spec.md`（仕様の正・「やらないこと」§5 を厳守）。

- **議員ページ** `/choken/[slug]/[year]`：B-1 使いみちの流れ（KPI2枚＋区分トグル＋サンキー・未使用は淡色で末尾固定）／B-2 1年間の推移（上下対向棒・未公開月は点線）／B-3 主要な支出の成果（活用方針＝グレー帯左太罫＋成果カード）／B-4 すべての支出（月切替必須・ⓘ特記事項・領収書チップ→モーダル）／B-5 データについて
- **政党ページ**：A-6 調研費セクション（KPI2枚・横棒・議員リスト＝行選択でグラフ絞り込み＋詳細ボタンで遷移・準備中議員もグレー表示）、組織セレクタの「政治資金2団体／調査研究費 議員n人」2グループ化、A-7 に調研費の記載追加
- データはすべて published のみ。CSVダウンロードも同様
- **やらないこと**（spec §5）：返還額のKPI化・円グラフ・議員リストのソート・準備中議員の非表示・調研費だけの特別な配色
