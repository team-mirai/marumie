# ⚠️ このディレクトリは「現行の正」ではありません

ここにあるのは **作成時点のスナップショット** です。
実装当時の設計メモ・要件定義・実装計画であり、**書かれた後に更新されていません**。
すでに廃止された設計、作り直された設計、実装されなかった案がそのまま残っています。

## 読むときのルール

- **現在の仕様の根拠にしないでください。** 「なぜこうなったか」の経緯を追うための資料です
- **記述と実装が食い違ったら、実装が正です**
- 現行のルール・仕様は [../README.md](../README.md) が示す正本を参照してください

## 新しい設計ドキュメントもここに置きます

設計メモ・要件定義・実装計画は、書かれた瞬間からスナップショットです。
新規に書く場合もこのディレクトリに `YYYYMMDD_HHMM_タイトル.md` の形式で追加してください。
