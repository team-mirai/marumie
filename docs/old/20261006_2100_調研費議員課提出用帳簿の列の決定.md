# 調研費 議員課提出用帳簿（衆議院・参議院フォーマット）の列の決定

#1654 で決めた、議員課に提出する Excel 用 CSV の各列に何を入れるかの記録。
決定の原文は #1654 のコメント。実装は #1660（CSV ダウンロード）で行う。

## 共通の決定

| 項目 | 決定 |
|------|------|
| CSV に含める仕訳 | **公開済み（`status = published`）の仕訳のみ**。下書き・確認済みは含めない |
| 行の単位 | 1 行 = 1 仕訳（1 枚の領収書に支出項目の違う明細が混ざることがあるため） |
| 文字コード | **UTF-8（BOM 付き）** |
| 支払先の氏名・住所の公開範囲 | admin と提出用 CSV だけ。**webapp の公開ページには出さない** |

## 列と値の対応

「null」は当面空欄で出す（値の決め方・持ち方が決まったら埋める）。

| 列 | 衆議院 | 参議院 | 入れる値 |
|----|:---:|:---:|----------|
| 支出項目 | ○ | ○ | 法定の区分（科目の区分） |
| 支出の目的 | ○ | ○ | 仕訳の公開用の項目名（`description`。「タクシー代」など） |
| 金額 | ○ | ○ | 仕訳の金額 |
| 年月日 | ○ | ○ | 仕訳の日付（`entry_date`） |
| 1万円超として扱う | - | ○ | null |
| 資金管理団体からの支出 | ○ | ○ | null |
| 支出を受けた者の氏名 | ○ | ○ | 支払先の名称（`research_fund_payees.name`） |
| 支出を受けた者の住所 | ○ | ○ | 支払先の住所（`research_fund_payees.address`） |
| 備考 | ○ | ○ | 仕訳の特記事項（`note`、公開される値）※ |
| 領収書等番号・徴難 | ○ | - | null |
| 領収書有無 | - | ○ | null |
| 領収書等を徴し難かった事情 | ○ | ○ | 仕訳の徴し難かった事情（`receipt_absence_reason`） |
| メモ | ○ | ○ | null |
| 特記事項 | - | ○ | null |
| 領収書画像ファイル名 | - | ○ | null |

※ 備考列の値は #1654 で明示されていない（「メモ・特記事項は null」とだけ決まった）。
仕訳の `memo` は「公開されない事務所内メモ」なので、提出用 CSV には出さず、公開される `note` を備考列に入れる前提にした。
違う場合は #1660 の着手前に #1654 / #1660 で修正する。

## 後回しにしたもの

- 領収書等番号の振り方・確定タイミング、領収書がないときの表記（衆議院「徴難」・参議院「無」）
- 領収書画像ファイル名の命名規則
- 「1万円超として扱う」の判定ルール（分割明細の合算・手動上書き）
- 「資金管理団体からの支出」の意味と、政治資金側の取引との突き合わせ

スキーマ上は `research_fund_documents.receipt_number`、`from_fund_management_org`、`treat_as_over_ten_thousand` を
持っている（#1673）が、当面 CSV には出さない。
