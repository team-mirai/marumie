# 調研費 領収書等番号の振り方と、領収書がないときの表記の決定

#1654 で「ひとまず null」とした、議員課提出用の帳簿の「領収書等番号・徴難」（衆議院）・「領収書有無」（参議院）・
「領収書画像ファイル名」（参議院）の 3 列の決定の記録。#1685 で決めた。
起票者の方針は「議員 slug + 年号で一意になるように」（#1685 のコメント）。

列全体の決定は [20261006_2100_調研費議員課提出用帳簿の列の決定.md](20261006_2100_調研費議員課提出用帳簿の列の決定.md) を参照。

## 一意になる範囲

**議員（slug）× 年度で一意**にする。帳簿（`research_fund_books`）は `(politician_id, financial_year)` で一意なので、
「帳簿の中で一意」と同じ意味になる。スキーマの `research_fund_documents.receipt_number` と
一意インデックス `(book_id, receipt_number)`（#1673）がこの範囲をそのまま表しているため、**スキーマ変更は要らない**。

## 領収書等番号の振り方

| 項目 | 決定 |
|------|------|
| 番号の形 | 帳簿（議員 × 年度）ごとに **1 から始まる整数の通し番号** |
| 単位 | 書類（`research_fund_documents`）ごとに 1 つ。1 枚の書類に複数の仕訳（明細）が紐づくときは、その全行に同じ番号が出る |
| 採番の対象 | **公開済みの仕訳が 1 件以上紐づいている書類**（提出用 CSV に出る行と揃える） |
| 振る順 | 書類に紐づく仕訳の**最も早い日付**の順。同じ日付なら書類の登録順（id 順） |
| 振るタイミング | 管理画面の帳簿で、事務担当者が明示的に「領収書等番号を振る」操作をしたとき。CSV のダウンロードでは振らない（副作用を持たせない） |
| 振り直し | **しない**。採番済みの番号は変えない（提出済みの帳簿・ファイル名と食い違わないようにするため） |
| 後から追加された書類 | 次の採番操作で、未採番の書類に **帳簿内の最大番号 + 1** から上の順で振る（日付順にならないことがある） |
| 書類の削除・仕訳の非公開化 | 番号は**欠番**のまま残し、詰めない |

日付順で振り直さない代わりに、年度の途中で追加された領収書は末尾の番号になる。
提出前にまとめて採番する運用なら、ほぼ日付順に並ぶ。

## 領収書がないときの表記

仕訳に書類が紐づいていない（`document_id` が NULL）ときの表記。

| 列 | 書類あり | 書類なし |
|----|----------|----------|
| 領収書等番号・徴難（衆議院） | 領収書等番号（未採番なら空欄） | `徴難` |
| 領収書有無（参議院） | `有` | `無` |

徴し難かった事情（`receipt_absence_reason`）が未入力でも、書類がなければ `徴難` / `無` と出す
（未入力は #1660 のダウンロード前の警告で知らせる）。

## 領収書画像ファイル名（参議院）

```text
{議員 slug}_{年度}_{領収書等番号を 4 桁ゼロ埋め}.{拡張子}
例: tanaka-taro_2026_0012.pdf
```

- 議員 slug と年度を含めることで、複数の議員・年度の画像を 1 か所に集めても名前がぶつからない
- 拡張子は書類の `mime` から決める（`image/jpeg` → `jpg`、`image/png` → `png`、`application/pdf` → `pdf`）
- 書類なし、または未採番の行は空欄
- ファイル名は番号から組み立てられるので DB には持たない。画像そのものの一括ダウンロードは別の話（#1660 の対象外）
